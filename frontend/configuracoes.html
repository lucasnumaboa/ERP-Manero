Como funciona

Quando ativado, o sistema enviará notificações via webhook para todos os vendedores ativos que possuem telefone cadastrado. As notificações são enviadas nos seguintes eventos:

  • Entrada de produtos: Quando uma compra é recebida
  • Saída de produtos: Quando uma venda é criada
  • Movimentação manual: Quando há entrada/saída manual no estoque
